## Finance Dashboard

The information we need for camps and clinics is the same we need for all finance dashboards (league registrations, sanctioned meets, NAIGC hosted meets, etc.). Basically PaySimple dumps lump sum deposits into our bank account on a daily basis with no detail as to what makes up those payments. We add all of those deposits over the course of each month to a single Accounts Receivable “invoice” and then at the end of the month pull reports from ScoreFlippers about what was purchased that month and then split/assign the total deposits to all the accounts the belong to (individual membership, club membership, coach membership, registration fees, banquet tickets, etc.). In addition to the information existing on each individual camp/clinic/meet page, it would be great if there was one master financial dashboard that shows this information across all financial transitions. Each dashboard (regardless of its in for an individual event or the aggregate one) should be filterable by any date range (would be great if the date range defaults were smart and auto set to the registration open date and one week after the meet date for events and for the previous month for the aggregate one) and show:

* Summary Tab  
  * One line item for each revenue type with accounting code  
    * Total net revenue  
    * Total gross revenue  
    * Total refunds  
    * Merchant fees collected  
    * Merchant fees charges/paid  
  * (for events) Meet Host Financials  
    * Amount owed to meet host (with the calc details of how we got there)  
    * Area to input payment information (i.e. date paid, check \#/PayPal account paid/ACH account paid)  
    * For the aggregate league-wide dashboard would also be good to see   
      * Total amount paid to meet hosts  
      * Total merchant fees collected  
      * Total merchant fee charges/paid  
      * Total merchant fee “profit” (=collected \- paid)  
  * Fully filterable by any of the columns  
  * Fully exportable (export should include ALL columns and ALL information in each of those columns)  
* Invoices/Transactions Tab  
  * It’s own tab and also navigates you to that tab from the summary tab if you want to click into the detail on any of the total revenue line items  
  * Shows ALL transactions (payments, refunds) with all description detail (date, name, email, club, transaction ID, invoice \#/refund \#, item description, any additional item note that was added, etc.)  
  * Fully filterable by any of the columns  
  * Fully exportable (export should include ALL columns and ALL information in each of those columns)  
* Financial league management   
  * Ability to set accounting codes to each of our purchase items and have those billing codes be a column that shows up on the summary tab (for each event and on the aggregate league-wide one)

## Registration

* Every event (camp, clinic, or competition) should have a unique registration page and an easy way to copy and share the link.  
  * For registration after a meet has closed, this link should have an extra password protection that can be set in the meet edit settings to allow registration for an event that looks closed. This late registration link should be different but ultimately go to the same place so that someone with the original registration link does not find it.  
  * After the “Final date/time/time zone to make corrections to registration”, even the password protected registration link will not work and only league admins can make changes.  
* On the registration page, users will be required to login. Logging in should return them to this page  
* If the logged in user is not a club admin:  
  * If the user does not have active membership, the page should inform them that they cannot register for any events until season membership has been purchased. There should be a link to the membership registration page that automatically sets the season to the correct season for that event (even if it isn’t the current active season)  
  * If the user does have active membership, then they will be able to click a link to open a popup for registering for the competition.  
    * The pop-up should have checkboxes for each discipline. When checked, it will then show the option to select the level and register for apparatuses with checkboxes or click All-around to select all apparatuses. T\&T is a bit different. There will be an option to set the default level, but then each selected apparatus has the option to select the level. You can also select All Apparatuses to select all T\&T events.For synchro trampoline, there is an option to select partner (from any athlete with active membership)  
      * If the athlete does not have a partner yet, they can check a box saying “Partner unknown” and they will not be required to select a partner. People who select this should be emailed with a link to edit this field of their registration 1 week before the last date to make changes. Editing the partner does not have a fee. This email is only triggered if they are not selected as the partner by someone else. The deadline to enter partners is the last day to make changes set in that event, though league admins and club managers or event admins set on the settings page can also edit this at any time up until a score is given.  
      * If the current user is selected by someone else, the field should be pre-filled with that name and if they change it, the person who had selected them should be changed to unknown partner and sent an email informing them that their synchro partner selected someone else and give them a link and a deadline to select a new partner (deadline is the last day to make changes set for that meet).  
    * Any add ons such as banquet ticket, tshirt, or leotard should have a check box to add purchase the appropriate dropdown for quantity, size, or text based on details above.  
      * Should be able to add multiple of any item and select the size for each, if applicable.  
    * Any survey questions (housing preferences for camps or session preferences for national competition should be last.  
    * When saved, there should be a summary of all add-ons and survey answers in the line item for that athlete. Only the competition details (not add-ons or survey questions) are subject to the change fee, but all are subject to the change deadline.  
* If the logged in user is a club admin (or a league admin)  
  * If the club they are an admin for (or for league admin, the club selected from the dropdown) does not have active club membership for the season, the page should inform them that they cannot register for any events until season membership for the club has been purchased. There should be a link to the membership registration page that automatically sets the season to the correct season for that event (even if it isn’t the current active season)
